# PMT 기록 커밋 경로: main 직접 기록 전용 커밋
## 문맥
PMT 기록(work/pmt/)을 레포 안에 둔다. 구현 단계는 작업마다 브랜치·PR이고 main 직접 push 금지(docs/09 7절). PMT 상태는 작업을 가로지르므로 브랜치별로 두면 충돌한다. GitHub main 보호 규칙 없음(1인 레포).
## 결정
PMT 변경(work/pmt/**만)은 오케스트레이터가 main에 기록 전용 커밋으로 직접 커밋·push한다. 기록 전용 커밋 정의와 CI 경로 필터에 work/pmt/**를 추가하고, main 직접 push 금지의 예외로 둔다. 강제 push는 계속 금지.
## 대안
B 레포 안·git 추적 제외(이력·다른 PC 재개 불가) / C 전용 브랜치 pmt를 별도 worktree로 운영(설정·경로 규칙 복잡)
