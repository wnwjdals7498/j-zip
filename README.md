# j-zip

7-Zip 오픈소스를 기반으로 **반디집 수준의 편의성**을 갖춘 압축 프로그램을 만들기 위한 기획 문서 모음.

> 7-Zip은 LGPL 오픈소스이므로 바이너리 리버스 엔지니어링이 아니라 **공개 소스를 읽고 수정(포크)** 하는 방식으로 진행한다.
> 반디집은 공개된 기능 목록과 실사용 UX만 벤치마크하며, 바이너리 분석이나 디자인·리소스 복제는 하지 않는다.
