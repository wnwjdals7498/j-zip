# 03. 기능 벤치마크 (반디집 기준)

기준: 반디집 공식 기능 페이지(v7.47)와 실사용 UX. 반디집 바이너리는 분석하지 않았다.
7-Zip 현황은 **7-Zip 26.04 소스로 검증**했다. 근거(파일·줄): [research/7zip-26.04-source-facts.md](research/7zip-26.04-source-facts.md)
기능별 세부 명세: [05. 기능 세부 명세](05-feature-specs/README.md)

표기: ✅ 있음 · △ 일부(있지만 불편) · ❌ 없음 · **N** = NanaZip에 구현됨(참고·이식 가능)
우선순위: P1 쉬움·효과 큼 · P2 중간 · P3 후순위
