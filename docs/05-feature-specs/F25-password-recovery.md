## 1. 목적

이 기능은 j-zip 범위에서 **제외**한다. 이 문서는 제외 이유와, 암호를 잊은 사용자를 위해 j-zip이 대신 제공하는 동작을 정리한다.

제외 이유:

- **범위**: 무차별 대입·사전 공격은 압축 프로그램의 본래 기능(만들기, 풀기, 관리)과 거리가 멀다. AES-256(#4)으로 보호된 아카이브는 실용적인 시간 안에 찾을 수 없는 경우가 대부분이라, 들인 노력에 비해 사용자가 얻는 것이 적다.
- **오용 위험**: 다른 사람의 암호 아카이브를 여는 데 쓰일 수 있다. 오픈 소스 포크에서 이런 기능을 기본 제공하면 배포·평판 위험이 생긴다.
- **유지 비용**: 성능 최적화(GPU 등)는 별도 전문 도구의 영역이고, 7-Zip 코드베이스에는 출발점이 없다.

## 2. 현재 7-Zip 동작

- 비밀번호 찾기 관련 코드 없음 (research #25 "관련 코드 없음").
- 암호가 틀리면 해제·테스트 결과에 오류로 표시되고, 사용자는 다시 입력하는 수밖에 없다. 입력 UI는 `CPP/7zip/UI/FileManager/PasswordDialog.cpp`, `CPP/7zip/UI/GUI/ExtractDialog.cpp`(`IDE_EXTRACT_PASSWORD 120`) (research #23).

## 3. 요구사항

- FR-25-1 j-zip은 암호를 추측·대입·사전 공격으로 찾는 기능, 명령, CLI 스위치를 제공하지 않는다.
- FR-25-2 대신 암호를 잊지 않도록 돕는 경로를 제공한다: 비밀번호 관리자(#23, S6-07~S6-11)에 맞는 암호를 저장하고, 풀 때 저장된 암호를 자동으로 시도한다(S6-09).
- FR-25-3 암호가 틀린 경우 S6에서 다시 입력을 받는다. 저장된 암호를 이미 시도했다면 S6-02에 그 사실을 표시한다.
- FR-25-4 테스트·해제 결과에서 암호 오류는 CRC 오류와 구분해 "암호 틀림"으로 표시한다(S9-02).

## 5. 동작 규칙과 예외

- 암호 오류 안내 문구는 06 문서의 문구 원칙(원인 + 해결 방법)을 따른다. 예: "암호가 맞지 않음 · 대소문자와 키보드 언어(한/영)를 확인하세요".
- "암호 찾기" 기능을 소개하거나 외부 도구로 안내하는 문구·링크는 넣지 않는다.
