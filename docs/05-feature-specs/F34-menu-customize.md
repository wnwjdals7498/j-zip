## 1. 목적

우클릭 메뉴에 쓰지 않는 항목이 많으면 원하는 항목을 찾기 어렵다. 7-Zip에도 항목 선택 기능은 있지만 체크 목록과 "하위 메뉴로 묶기" 하나뿐이다. 항목마다 "맨 위에 / j-zip 안에 / 숨김"을 고르게 하고, 우클릭 메뉴에서 바로 이 설정으로 갈 수 있게 한다.

## 2. 현재 7-Zip 동작

- `CPP/7zip/UI/FileManager/MenuPage.cpp:49-70` `kMenuItems[]` 체크 목록, `IDX_SYSTEM_CASCADED_MENU`(하위 메뉴로 묶기), `IDX_SYSTEM_ICON_IN_MENU`(아이콘), `IDX_EXTRACT_ELIM_DUP`, `IDC_SYSTEM_ZONE` (`MenuPageRes.h`). `OnInit` 96행, `OnApply` 299행 (research #34).
- 플래그는 `CPP/7zip/UI/Explorer/ContextMenuFlags.h`, 저장은 `UI/Common/ZipRegistry.h:190` `CContextMenuInfo` (research #34).
- 빠른 압축은 7z/zip만 있다(`kCompressTo7z`, `kCompressToZip`) (research #34).
- 사용자 입장: 항목마다 켜고 끌 수 있고, "하위 메뉴로 묶기"는 전체에 한 번에 적용된다. 항목별로 일부만 맨 위에 두는 것은 안 된다.

## 3. 요구사항

- FR-34-1 S8-05 표에서 항목마다 "맨 위에 / j-zip 안에 / 숨김" 중 하나를 고른다. 대상 항목은 S7-01, S7-02, S7-04~S7-08, S7-10, S7-11, S7-13의 항목이다.
- FR-34-2 기본값: S7-01, S7-02, S7-10, "{이름}.zip으로 압축" = 맨 위에, 나머지 = j-zip 안에.
- FR-34-3 S8-06 "메뉴에 아이콘 표시"(기본 켜짐), "Shift 누를 때만 표시"(기본 꺼짐)를 둔다. "Shift 누를 때만 표시"가 켜지면 Shift + 우클릭일 때만 j-zip 항목이 나온다.
- FR-34-4 S7-09 "메뉴 항목 편집…"은 S8을 탐색기 메뉴 탭이 선택된 상태로 연다.
- FR-34-5 저장하면 탐색기를 다시 시작하지 않고 다음 우클릭부터 반영된다.
- FR-34-6 기존 7-Zip 설정(`CContextMenuInfo`)에서 j-zip으로 처음 옮길 때, 꺼져 있던 항목은 "숨김", 켜져 있던 항목은 "j-zip 안에"(묶기 켜짐) 또는 "맨 위에"(묶기 꺼짐)로 옮긴다.
- FR-34-7 S8-10 "기본값"은 탐색기 메뉴 탭의 값만 FR-34-2 기본값으로 되돌린다.

## 5. 동작 규칙과 예외

- S7-09 "메뉴 항목 편집…" 자체는 숨길 수 없다(설정으로 돌아올 길이 없어지므로). 다만 "Shift 누를 때만 표시"가 켜지면 함께 숨겨진다.
- 모든 항목이 "숨김"이면 S7-03 "j-zip ▸"도 숨긴다. 이때도 S8은 시작 메뉴의 j-zip에서 열 수 있다.
- Win11 새 메뉴(#19)는 최상위에 보일 수 있는 항목 수가 제한될 수 있다. "맨 위에"가 많으면 일부가 "j-zip 안에"로 표시될 수 있다는 안내를 S8-05 아래에 보조 텍스트로 둔다(9절 미결).
- 항목 문구의 `{이름}`은 실제 선택한 파일 이름으로 바뀌며, 표에는 "이름"으로 표시한다.
- 여러 개 선택 시 항목(S7-10)과 일반 파일 항목(S7-11)은 해당 상황에서만 나타난다.

## 7. 구현 지점

- 설정 페이지: `JZip.exe`(WinUI 3) S8 탐색기 메뉴 탭(S8-04~S8-06)을 새로 만든다. 7zFM 설정 페이지 `CPP/7zip/UI/FileManager/MenuPage.cpp`(`kMenuItems[]` 49-70행, `OnInit` 96행, `OnApply` 299행), `MenuPage.rc`, `MenuPageRes.h`는 현재 항목·동작 근거로만 쓴다 (research #34).
- 플래그: `CPP/7zip/UI/Explorer/ContextMenuFlags.h` (research #34). 항목별 위치를 담으려면 현재의 켬/끔 비트 외에 위치 값이 필요하다.
- 저장: `jzip-core` 설정(기존 `CPP/7zip/UI/Common/ZipRegistry.h:190` `CContextMenuInfo` 기반, research #34). `JZip.exe`(패키지 앱)가 쓴 값을 탐색기 안의 `jzip-shell.dll`이 읽을 수 있는 위치에 둔다(9절 미결).
- 메뉴 구성(`jzip-shell.dll`): `CPP/7zip/UI/Explorer/ContextMenu.cpp` `QueryContextMenu`(700~1100행대) (research #18), Win11 메뉴는 `EnumSubCommands`(1756행) (research #19). 등록은 MSIX 매니페스트(#19).

## 8. 수용 기준

- [ ] 새로 설치한 뒤 `a.zip`을 우클릭하면 S7-01, S7-02가 맨 위에, S7-04~S7-08이 "j-zip ▸" 안에 있다.
- [ ] S8-05에서 "압축 파일 테스트"를 "맨 위에"로 바꾸고 저장하면, 탐색기를 다시 시작하지 않고 다음 우클릭에서 맨 위에 나온다.
- [ ] "다른 위치에 풀기…"를 "숨김"으로 바꾸면 메뉴 어디에도 나오지 않는다.
- [ ] "Shift 누를 때만 표시"를 켜면 일반 우클릭에 j-zip 항목이 없고, Shift + 우클릭에는 나온다.
- [ ] "메뉴에 아이콘 표시"를 끄면 j-zip 항목 아이콘이 사라진다.
- [ ] S7-09를 누르면 S8이 열리고 탐색기 메뉴 탭이 선택돼 있다.
- [ ] 7-Zip에서 "Test archive"를 꺼 둔 설정으로 j-zip을 처음 실행하면 S8-05에서 "압축 파일 테스트"가 "숨김"이다.
- [ ] S8-10 "기본값"을 누르면 탐색기 메뉴 탭만 FR-34-2 값으로 돌아가고 다른 탭 값은 그대로다.

## 9. 범위 밖·미결 사항

- 범위 밖: 사용자가 메뉴 항목 순서를 끌어서 바꾸는 기능, 사용자 정의 명령 추가.
- 미결: Win11 새 메뉴에서 앱 하나가 최상위에 둘 수 있는 항목 수와 하위 메뉴 구성 방식은 research 자료에서 확인하지 않았다(#19의 `GetFlags`/`EnumSubCommands` 확인 필요).
- 해결: 7-Zip의 기존 해시 메뉴는 유지한다. 06에 S7-13 "해시 값 계산 ▸"를 추가하고 S8-05 항목 목록에 넣었다.
- 해결: 제품 화면 문구는 "j-zip 안에"(S8-05), "j-zip ▸"(S7-03)로 통일했다(06, 04). Settings·ContextMenu 디자인의 "7-Zip" 표기는 디자인 쪽에서 고친다.
- 미결: Settings.dc.html의 항목 이름 `"폴더명\"에 풀기`와 06 문서 S7-02 `"{이름}\"에 풀기`의 표기 차이.
- 미결: 메뉴 설정 저장 위치. MSIX 앱의 앱 데이터·레지스트리 쓰기는 패키지 안으로 가상화될 수 있으므로, 탐색기 프로세스에서 도는 `jzip-shell.dll`이 같은 값을 읽을 수 있는 방식(패키지 설정 API 등)을 SP-1에서 함께 확인한다.
