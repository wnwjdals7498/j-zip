## 1. 목적

j-zip의 모든 화면을 사용자의 언어로 보여 준다. 7-Zip에는 `Lang\*.txt` 번역 파일 구조가 있지만, j-zip 화면은 WinUI 3 앱 `JZip.exe`에 새로 만들므로([07. 기술 스택](../07-tech-stack.md)) 문구 리소스 방식을 새로 정한다(7절, 9절). j-zip에서 새로 생긴 문구(S1~S9, D1~D3)를 번역 대상에 넣고, 언어 선택을 S8 화면·언어 탭에 둔다.

## 2. 현재 7-Zip 동작

- `CPP/7zip/UI/FileManager/LangUtils.cpp:33-36` `GetLangDirPrefix()`: 실행 폴더 아래 `Lang\`.
- 언어 선택 페이지: `CPP/7zip/UI/FileManager/LangPage.cpp`.
- 소스 레포에는 `Lang\*.txt` 번역 파일이 없다(`DOC/`에도 없음). 7-Zip 바이너리 배포판에만 들어 있다.
- 사용자 입장: 설정의 언어 탭에서 언어를 고르면 다음 창부터 바뀐다.

## 3. 요구사항

- FR-22-1 S8-09 화면·언어 탭에 언어 드롭다운(S8-15)을 둔다. 첫 항목은 "시스템 설정 따르기"이며 기본값이다.
- FR-22-2 "시스템 설정 따르기"는 Windows UI 언어에 맞는 번역 파일을 고르고, 없으면 영어를 쓴다.
- FR-22-3 언어 목록은 j-zip 패키지에 포함된 번역 리소스에서 만들고, 각 언어 이름은 그 언어로 표시한다(예: "한국어", "English").
- FR-22-4 j-zip이 새로 만든 모든 문구(06 문서 S1~S9 요소의 문구)는 번역 키를 가진다. 소스 코드에 사용자에게 보이는 한국어·영어 문자열을 직접 쓰지 않는다.
- FR-22-5 j-zip은 최소한 한국어와 영어 번역을 함께 배포한다.
- FR-22-6 언어를 바꾸고 S8-10 [저장]하면 열려 있는 S1 창의 메뉴·툴바·상태 줄이 즉시 바뀐다. 이미 열린 다른 대화상자는 다음에 열 때 바뀐다.
- FR-22-7 번역 리소스에 없는 키는 영어 문구로 표시한다.
- FR-22-8 셸 메뉴(S7) 문구도 같은 언어 설정을 따른다.

## 5. 동작 규칙과 예외

- 문구 길이는 영어 기준 +30% 여유를 둔다(06 문서 2절). 번역이 길어 넘치면 줄임표 대신 줄바꿈 또는 툴팁으로 전체를 보인다.
- 오른쪽에서 왼쪽으로 쓰는 언어(아랍어 등)의 레이아웃 반전은 범위 밖이다.
- 7-Zip `Lang\` 번역 파일을 재사용하기로 정하면(9절), 그 파일에 없는 j-zip 신규 키는 영어로 보인다(FR-22-7).

## 7. 구현 지점

- `JZip.exe`(WinUI 3) 화면: S8 화면·언어 탭(S8-09, S8-15)을 새로 만든다. 7zFM의 `CPP/7zip/UI/FileManager/LangUtils.cpp`(`GetLangDirPrefix` 33-36행), `LangPage.cpp`는 현재 동작 근거로만 쓴다.
- 문구 리소스: WinUI 3 기본 방식인 `.resw` 리소스 파일 + MRT Core(`Microsoft.Windows.ApplicationModel.Resources`, `x:Uid`)를 기본안으로 한다. "시스템 설정 따르기"는 Windows 표시 언어에 맞는 리소스를 고르고, 직접 고른 언어는 MRT 언어 재정의로 적용한다.
- `jzip-shell.dll`(S7 문구): 탐색기 프로세스 안에서 같은 언어 설정과 리소스를 읽는 방법이 필요하다(9절).
- 7-Zip `Lang\*.txt` 번역 파일은 소스 레포에 없고 바이너리 배포판에만 있다(research 자료 #22). 재사용 여부는 9절 미결.

## 8. 수용 기준

- [ ] Windows 표시 언어 한국어에서 처음 실행하면 S1이 한국어다.
- [ ] Windows 표시 언어 영어에서 처음 실행하면 S1이 영어다.
- [ ] S8-15에서 "English"를 고르고 저장하면 열린 S1의 툴바 라벨이 즉시 영어로 바뀐다.
- [ ] j-zip에 번역 리소스가 없는 언어(예: 아이슬란드어)인 Windows에서 "시스템 설정 따르기"이면 영어로 보인다.
- [ ] 한국어 번역 리소스에서 S2-05 키 한 줄을 지우면 그 문구만 영어로 보인다.
- [ ] 언어를 바꾼 뒤 탐색기 우클릭(S7) 문구도 바뀐다.

## 9. 범위 밖·미결 사항

- 범위 밖: 한국어·영어 이외 언어의 번역 작업 자체, RTL 레이아웃.
- 미결: 7-Zip `Lang\*.txt` 번역 파일 재사용 여부. (a) `.resw`만 쓰고 7-Zip 번역은 참고·변환 자료로만 쓰는 안, (b) 7-Zip 번역 파일을 런타임에 읽어 `.resw`와 함께 쓰는 안 중에서 정한다. 7-Zip 화면을 대체하므로 7-Zip 번역 문구 중 그대로 쓸 수 있는 비율, 번역 파일(바이너리 배포판)의 라이선스와 포함 여부를 함께 확인해야 한다. 07 문서와 조사 자료는 이 결정을 다루지 않는다.
- 미결: MRT Core로 실행 중 언어를 바꿀 때 이미 그려진 XAML 문구를 다시 읽는 방법(FR-22-6의 즉시 반영 범위).
- 미결: 셸 확장(`jzip-shell.dll`, S7)이 패키지의 번역 리소스와 언어 설정을 어떻게 읽는지, 언어 변경을 언제 다시 읽는지(탐색기 재시작 필요 여부)는 research 자료에 근거가 없다.
- 06에 반영됨 (S8-14 테마, S8-15 언어). Settings 디자인의 화면·언어 탭 아트보드는 디자인 쪽에서 추가한다.
