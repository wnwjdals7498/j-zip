## 1. 목적

아카이브 안 파일 몇 개만 필요할 때 끌어서 원하는 폴더에 놓는 것이 가장 빠르다. 7-Zip도 끌어내기를 지원하지만 탐색기로 놓을 때 임시 폴더에 먼저 풀고 다시 복사하므로 큰 파일은 두 번 쓰게 되어 느리고, 임시 폴더 디스크 공간도 필요하다. j-zip은 놓은 위치에 바로 풀리게 한다.

## 2. 현재 7-Zip 동작

- `CPP/7zip/UI/FileManager/PanelDrag.cpp:1500` `CPanel::OnDrag`, `:1522` `CTempDir tempDirectory`, 임시 폴더 접두사 `:76` `kTempDirPrefix FTEXT("7zE")`.
- 탐색기에는 `CF_HDROP`으로 임시 폴더 경로를 넘김 (`:585`). 데이터 객체는 `CDataObject`(`:476`, `IDataObject`), 드롭 소스는 `CDropSource`(`:1219`).
- 목적지가 7-Zip FM 패널이면 `DestDirPrefix_FromTarget`(`:557`, `:1746-1769`)로 임시 폴더 없이 `CopyTo`로 바로 풂. 소스와 타깃 사이 플래그 프로토콜은 72~200행 주석(`k_SourceFlags_TempFiles`, `k_SourceFlags_NamesAreParent` 등).
- 가상 파일 형식(`CFSTR_FILEDESCRIPTOR`/`CFSTR_FILECONTENTS`)은 not found.
- 사용자 입장: 탐색기로 큰 파일을 끌어 놓으면 임시 폴더에 다 풀린 뒤에야 복사가 시작되어 오래 걸림.

## 3. 요구사항

- FR-11-1 S1-14에서 파일·폴더를 골라 탐색기 창 또는 바탕 화면에 끌어 놓으면 놓은 위치에 풀린다. 폴더 구조(선택한 폴더 아래)는 유지한다.
- FR-11-2 탐색기 대상으로 놓을 때 아카이브 전체 크기만큼의 임시 사본을 만들지 않는다. 임시 폴더를 쓰더라도 놓은 위치로 이동(같은 볼륨) 또는 직접 쓰기로 처리해 데이터를 두 번 쓰지 않는 것을 목표로 한다(방식은 §9).
- FR-11-3 끌어 놓은 뒤 풀기는 S4 진행창으로 보여 준다. 진행 중 S1은 계속 쓸 수 있다.
- FR-11-4 암호가 필요한 항목이면 놓은 직후 S6를 띄운다. 취소하면 아무것도 쓰지 않는다.
- FR-11-5 놓은 위치에 같은 이름이 있으면 S2-09 기본값(같은 파일 처리) 규칙을 따른다. "매번 묻기"면 묻는다.
- FR-11-6 끌어내기를 취소하거나(`Esc`, 원래 창에 놓기) 풀기가 실패하면 놓은 위치에 일부만 쓰인 파일을 남기지 않는다.
- FR-11-7 작업이 끝나면 j-zip이 만든 임시 폴더를 모두 지운다.
- FR-11-8 S1-14 안에서 같은 아카이브로 다시 놓는 경우는 아무 동작도 하지 않는다.
- FR-11-9 S1-15 안내 상자는 아카이브를 열었을 때 목록 아래에 표시한다.

## 5. 동작 규칙과 예외

- 놓는 대상이 압축 파일을 받는 다른 프로그램(메일 첨부 창 등)이면 그 프로그램이 파일 경로를 요구하므로 임시 폴더 방식으로 처리한다. 이 경우 임시 폴더는 대상 프로그램이 복사를 마친 뒤 지운다.
- 대상이 다른 j-zip S1 창이면 7-Zip의 FM 대상 직접 풀기(`DestDirPrefix_FromTarget`) 경로를 그대로 쓴다.
- 오른쪽 버튼으로 끌어 놓으면 탐색기 메뉴(복사/이동)를 따른다. "이동"은 "복사"로 처리한다(아카이브에서 지우지 않음).
- 놓은 위치가 읽기 전용이거나 공간이 부족하면 S4에서 원인과 해결 방법을 표시한다.

## 8. 수용 기준

- [ ] 3GB 동영상 1개가 든 ZIP(저장만)을 S1에서 열고 바탕 화면으로 끌어 놓기 → 바탕 화면에 파일 생성, 원본과 SHA-256 일치
- [ ] 위 작업 중 `%TEMP%` 사용량이 3GB 늘어나지 않음(같은 볼륨 이동 방식이면 놓은 위치 볼륨 기준으로 확인)
- [ ] 위 작업이 같은 PC의 7-Zip 26.04 끌어내기보다 빠르거나 같음
- [ ] 폴더 `여행\제주`를 끌어 놓기 → `제주` 폴더와 하위 구조가 그대로 생김
- [ ] 암호 걸린 항목 끌어 놓기 → S6 표시, 취소 시 대상 폴더에 아무것도 없음
- [ ] 큰 파일 끌어내기 중 S4 "취소" → 대상 폴더에 부분 파일 없음
- [ ] 작업 후 `%TEMP%`에 j-zip 임시 폴더가 남지 않음

## 9. 범위 밖·미결 사항

- 범위 밖: 탐색기에서 S1으로 끌어 놓아 추가하기(#14).
- 미결: FR-11-2 구현 방식. (a) 가상 파일 형식(`CFSTR_FILECONTENTS`)으로 탐색기가 스트림을 직접 읽게 하기 — 폴더·대용량·진행 표시 처리 범위 확인 필요. (b) 놓은 위치를 알아낸 뒤 그 위치에 직접 풀기 — 탐색기 대상에서 놓은 위치를 얻는 방법이 research 자료에 없다.
- 미결: 가상 파일 방식에서 S4 진행창을 띄울 수 있는지(탐색기가 복사 진행을 표시할 수 있음).
- 불일치 없음. 단, 06 S1-15 "탐색기로 끌어내기 = 바로 풀기"는 진행 표시(S4) 여부를 정의하지 않는다. 이 문서는 S4를 띄우는 것으로 정했다.
