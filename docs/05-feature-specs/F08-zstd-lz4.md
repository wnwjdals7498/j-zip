## 1. 목적

리눅스 배포판, 게임·백업 도구에서 `.zst`, `.lz4` 파일을 흔히 받는다. 7-Zip은 ZSTD는 풀지만 LZ4는 열지 못한다. j-zip은 LZ4 해제를 추가해 두 형식을 같은 방식으로 다루게 한다.

## 2. 현재 7-Zip 동작

- ZSTD: `CPP/7zip/Archive/ZstdHandler.cpp` (시그니처 `0x28 b5 2f fd` 428-429행, 등록 1139행 `"zstd", "zst tzst"`), 디코더 `CPP/7zip/Compress/ZstdDecoder.cpp`, `C/ZstdDec.c`.
- ZSTD 생성은 꺼져 있음: `ZstdHandler.cpp:6` `Z7_USE_ZSTD_COMPRESSION` 주석 처리, `ZstdEncoder.h` 없음.
- LZ4: `SquashfsHandler.cpp:70` `// #define kMethod_LZ4  5`(주석)과 메서드 이름 문자열뿐. 디코더 없음.
- 그 밖에 `Compress/LzfseDecoder.cpp`(LZFSE)가 있음.
- 사용자 입장: `.zst`는 열면 안쪽 파일 1개가 보이고 풀 수 있음. `.tar.zst`는 `.tar` 하나가 나옴(#12). `.lz4`는 열 수 없음.

## 3. 요구사항

- FR-08-1 `.lz4` 파일(LZ4 프레임 형식)을 S1에서 열면 안쪽 파일 1개가 S1-14에 보이고, 이름은 `.lz4`를 뗀 원래 이름이다.
- FR-08-2 형식 판별은 LZ4 프레임 시그니처로 한다(확장자가 달라도 열림).
- FR-08-3 `.lz4`도 S2, S7-01, S7-02, 무결성 테스트(S1-06)가 다른 단일 파일 압축 형식과 같이 동작한다. 체크섬이 들어 있는 프레임이면 테스트에서 검사한다.
- FR-08-4 `.tar.lz4`는 #12(F12) "tar 한 번에 풀기" 대상에 포함한다.
- FR-08-5 ZSTD 해제는 7-Zip 동작을 유지한다. `.tar.zst`, `.tzst`는 #12 대상이다.
- FR-08-6 S1-21 형식 칸에 "ZSTD" 또는 "LZ4"를 표시한다.
- FR-08-7 ZSTD·LZ4 생성은 제공하지 않는다(S3 형식 목록에 없음).
- FR-08-8 S8-07 연결 프로그램 목록에 `.zst`, `.lz4`를 추가한다.

## 5. 동작 규칙과 예외

- 여러 프레임이 이어 붙은 LZ4 파일은 하나의 출력으로 이어서 푼다.
- 데이터가 중간에 끝나면 S9-02에 "데이터 끝남"으로 표시하고, 그때까지 푼 내용은 남기지 않는다(다른 형식과 같은 오류 처리).
- LZ4 레거시 형식(프레임 이전 형식) 지원 여부는 §9 미결.

## 7. 구현 지점

- LZ4 디코더를 `CPP/7zip/Compress/`에 추가.
- LZ4 핸들러를 `CPP/7zip/Archive/`에 `ZstdHandler.cpp`를 본떠 추가하고 읽기 전용으로 등록.
- 포맷 등록 후 빌드 목록에 포함(Format7zF makefile — research 자료에서 내용은 확인하지 않음).

## 8. 수용 기준

- [ ] `lz4 -z data.bin` 으로 만든 `data.bin.lz4`를 S1에서 열기 → `data.bin` 1개 표시
- [ ] 위 파일을 S7-01로 풀기 → 원본과 SHA-256 일치
- [ ] `data.bin.lz4`를 `data.dat`로 이름 바꿔 열기 → LZ4로 인식
- [ ] 끝을 잘라낸 `.lz4` → 테스트에서 "데이터 끝남"
- [ ] `zstd` 도구로 만든 `log.txt.zst` → 7-Zip과 같이 열리고 풀림(회귀 없음)
- [ ] S3 형식 목록에 ZSTD·LZ4가 없음

## 9. 범위 밖·미결 사항

- 범위 밖: ZSTD·LZ4 생성(ZSTD 인코더 소스 없음).
- 미결: LZ4 디코더를 새로 작성할지 외부 구현을 가져올지, 그리고 라이선스 확인. research 자료에 후보가 없다.
- 미결: LZ4 레거시 형식과 Skippable 프레임 처리 범위.
- 해결: 06 S2-08 표시 대상에 `.tzst`를 넣었고, LZ4 핸들러가 들어가면 `.tar.lz4`도 포함한다고 적었다(FR-08-4/5).
