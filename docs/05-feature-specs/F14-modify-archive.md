## 1. 목적

아카이브에 파일 하나를 더 넣거나 빼려고 전체를 풀었다가 다시 압축하는 일을 없앤다.
7-Zip에는 이미 있는 기능이므로, 새 S1 화면에서 같은 기능을 찾기 쉽게 배치하는 것이 목표다.

## 2. 현재 7-Zip 동작

- 구현: `CPP/7zip/UI/Agent/AgentOut.cpp`, `ArchiveFolderOut.cpp`, `UpdateCallbackAgent.cpp`. 7zFM 패널에서 아카이브를 폴더처럼 열어 추가, 삭제, 이름 변경을 하면 아카이브를 갱신한다.
- 사용자 입장: 7zFM에서 파일을 끌어 놓거나 메뉴 명령으로 추가·삭제할 수 있다. 수정할 수 없는 형식(읽기 전용 핸들러)에서는 오류가 난다.

## 3. 요구사항

- FR-14-1 S1-04 "파일 추가"는 파일 선택 대화상자에서 고른 파일을 현재 S1-11 경로(아카이브 안 폴더)에 추가한다.
- FR-14-2 S1-05 "삭제"와 `Del` 키는 확인 대화상자 뒤 선택 항목을 아카이브에서 지운다.
- FR-14-3 S1-15 드롭 영역이나 S1-14 목록에 탐색기 파일을 끌어 놓으면 현재 경로에 추가한다.
- FR-14-4 S1-14에서 이름 바꾸기(F2 또는 우클릭)를 하면 아카이브 안 항목 이름을 바꾼다.
- FR-14-5 쓰기를 지원하지 않는 형식(예: ISO, RAR)을 열었을 때 S1-04·S1-05는 비활성이고, 툴팁에 "이 형식은 수정할 수 없음"을 표시한다.
- FR-14-6 수정 진행 상황은 S4로 표시한다.

## 4. GUI 명세

| ID | 상태·표시 조건 | 문구 | 동작 |
|---|---|---|---|
| S1-04 | 쓰기 지원 형식이면 활성 | "파일 추가" | 파일 선택 → 현재 경로에 추가 → S4 |
| S1-05 | 항목 선택 + 쓰기 지원 형식 | "삭제" | 확인 "선택한 N개를 압축 파일에서 삭제함" → S4 |
| S1-14 | 항상 | 파일 목록 | 이름 바꾸기, 끌어 놓기 대상 |
| S1-15 | 항상 | "여기로 끌어 놓으면 이 압축 파일에 추가 · 목록에서 탐색기로 끌어내면 바로 풀기" | 끌어 놓기 = 추가 |

## 5. 동작 규칙과 예외

- 암호가 걸린 아카이브에 추가할 때 기존 7-Zip 동작(암호 입력 요청)을 따른다.
- 분할 아카이브와 솔리드 7z 수정 가능 여부와 오류 문구는 기존 7-Zip 동작을 그대로 쓴다.
- 같은 이름 항목이 있으면 기존 7-Zip의 덮어쓰기 확인을 따른다.

## 8. 수용 기준

- [ ] `t.zip`을 S1에서 열고 S1-04로 `new.txt`를 추가하면, 다시 열었을 때 `new.txt`가 목록에 있다.
- [ ] `t.zip`에서 `old.txt`를 선택하고 `Del` → 확인하면 `old.txt`가 목록에서 사라지고 `7z t t.zip`이 오류 없이 끝난다.
- [ ] 탐색기의 `a.jpg`를 S1-15에 끌어 놓으면 현재 경로에 추가된다.
- [ ] `x.iso`를 열면 S1-04·S1-05가 비활성이고 툴팁이 보인다.

## 9. 범위 밖·미결 사항

- 범위 밖: 수정 속도 개선(솔리드 아카이브 재압축 비용).
- 06에 반영됨: `F2` 이름 바꾸기는 06 문서 5절 "7zFM 기존 단축키" 목록에 있다(FR-14-4).
- 미결: 쓰기 지원 여부를 S1이 미리 아는 방법(핸들러의 쓰기 등록 여부 조회)은 research 자료에 GUI 쪽 근거가 없다. #5의 `REGISTER_ARC_IO` 등록 여부가 기준이 될 것으로 보이나 확인이 필요하다.
