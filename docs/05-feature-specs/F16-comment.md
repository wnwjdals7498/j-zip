## 1. 목적

배포용 ZIP·RAR에는 설명, 저작권, 비밀번호 힌트가 주석으로 들어 있는 경우가 많다. 지금은 속성 창을 따로 열어야 보이고, 한글 주석이 다른 로캘 PC에서 깨진다.
아카이브를 열면 미리보기 창에 주석을 바로 보여 주고, 파일명과 같은 코드페이지로 읽는다.

## 2. 현재 7-Zip 동작

- 아카이브 주석 속성은 `kpidComment`.
  - ZIP: `CPP/7zip/Archive/Zip/ZipHandler.cpp:227` `MultiByteToUnicodeString(BytesToString(m_Archive.ArcInfo.Comment), CP_ACP)`. **`CP_ACP`로 고정**되어 있고 `-mcp`로 준 `_specifiedCodePage`를 무시한다.
  - RAR5: `CPP/7zip/Archive/Rar/Rar5Handler.cpp:1575`.
  - 구RAR(RAR4 이하): `RarHandler.cpp:791`, `:1015`에서 `kpidCommented` 플래그만 낸다. 주석 내용은 나오지 않는다.
- 7zFM 표시: `CPP/7zip/UI/FileManager/PanelMenu.cpp:172` `CPanel::Properties()`가 `IGetFolderArcProps`로 속성 목록을 보여 줄 때만 나온다.
- `IDM_COMMENT`/`CPanel::ChangeComment`(`PanelOperations.cpp:487`)는 항목 단위 주석 편집이며 주로 FS 폴더의 `descript.ion`용이다(`FSFolder.cpp:334`). 아카이브 주석 보기와는 다르다.
- 사용자 입장: 주석이 있는지 열어 봐야 알 수 있고, 한국어 Windows가 아닌 PC에서 CP949 주석은 깨진다.

## 3. 요구사항

- FR-16-1 아카이브를 S1에서 열 때 `kpidComment`를 읽어 S1-18에 표시한다. 값이 없거나 빈 문자열이면 S1-18 영역 전체(제목 포함)를 숨긴다.
- FR-16-2 ZIP 주석은 파일명과 같은 코드페이지로 디코딩한다. 즉 S1-12/S5에서 고른 코드페이지(#17)가 주석에도 적용된다.
- FR-16-3 S5에서 인코딩을 바꿔 [적용]하면 S1-18도 다시 읽는다.
- FR-16-4 S1-18은 읽기 전용이며 텍스트 선택·복사(`Ctrl+C`)가 된다. 줄바꿈(CR, LF, CRLF)을 그대로 보여 준다.
- FR-16-5 주석이 6줄을 넘으면 S1-18 안에 세로 스크롤을 표시한다. 영역 높이는 최대 6줄이다.
- FR-16-6 구RAR처럼 주석 존재만 알 수 있는 경우 S1-18에 "이 형식의 주석은 표시하지 못함"을 보조 텍스트로 표시한다.
- FR-16-7 주석에 제어 문자(탭, 줄바꿈 제외)가 있으면 공백으로 바꿔 표시한다.

## 5. 동작 규칙과 예외

- ZIP 주석이 UTF-8로 유효하고 0x80 이상 바이트를 포함하면 UTF-8 후보에 가산점을 준다(#17 감지 알고리즘에 주석 바이트를 함께 넣는다). 주석만 있고 파일명이 모두 ASCII인 ZIP에서도 감지가 동작하게 하기 위함이다.
- 주석 길이는 ZIP 형식상 최대 65,535바이트다. 이 범위 안에서 잘라내지 않고 모두 표시한다.
- 주석 표시는 아카이브 열기를 늦추지 않아야 한다. 주석은 이미 읽은 헤더에 있으므로 추가 I/O는 없다.
- 7z 형식은 아카이브 주석이 없으므로 S1-18은 항상 숨는다.
- 주석 편집은 범위 밖이다(9절).

## 7. 구현 지점

- `CPP/7zip/Archive/Zip/ZipHandler.cpp:227`: `CP_ACP` 대신 `_forceCodePage`/`_specifiedCodePage`가 있으면 그 코드페이지를 쓰고, 없으면 #17 감지 결과(또는 기존 `GetCodePage()` 규칙)를 쓰도록 고친다.
- `jzip-core`: 아카이브를 열 때 `IGetFolderArcProps`로 `kpidComment`를 읽어 `JZip.exe`(WinUI 3) S1-18에 넘긴다. 기존 파일 `CPP/7zip/UI/FileManager/Panel.cpp`/`PanelFolderChange.cpp`, `PanelMenu.cpp:172` `CPanel::Properties()`의 읽기 방식을 참고한다.

## 8. 수용 기준

- [ ] 주석 "안녕하세요\r\n배포용 파일입니다"(CP949로 저장)가 있는 `kc.zip`을 한국어 Windows에서 열면 S1-18에 두 줄로 바르게 보인다.
- [ ] 같은 `kc.zip`을 시스템 로캘이 영어(미국)인 Windows에서 열고 S5에서 CP949를 적용하면 S1-18 주석이 바르게 보인다. (현재 7-Zip은 `-mcp=949`를 줘도 주석이 깨진다.)
- [ ] 주석 없는 `n.zip`을 열면 S1-18 제목과 본문 모두 보이지 않는다.
- [ ] 주석이 있는 RAR5 `r5.rar`를 열면 S1-18에 주석이 보인다.
- [ ] 주석이 있는 RAR4 `r4.rar`를 열면 "이 형식의 주석은 표시하지 못함"이 보인다.
- [ ] 20줄짜리 주석은 S1-18 안에서 스크롤되고, 전체 선택 후 `Ctrl+C`로 복사한 내용이 원문과 같다.
