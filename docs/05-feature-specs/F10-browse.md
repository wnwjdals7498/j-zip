## 1. 목적

아카이브 안에 무엇이 있는지 확인하려고 매번 풀 필요가 없게 한다. 7-Zip은 이미 아카이브를 폴더처럼 탐색할 수 있으므로 기능은 그대로 쓰고, j-zip은 폴더 트리·브레드크럼·정보 창으로 탐색을 쉽게 만든다.

## 2. 현재 7-Zip 동작

- `CPP/7zip/UI/Agent/Agent.cpp` (`CAgent::Open` 1628행), `ArchiveFolder.cpp`, `AgentProxy.cpp`. FM 패널에서 아카이브를 폴더처럼 열고 들어가고 나옴.
- 사용자 입장: 7zFM에서 아카이브를 더블클릭하면 목록 패널에 내부 항목이 보임. 폴더 트리 창은 없음(`CPP/7zip/UI/FileManager`에서 `WC_TREEVIEW`/`TreeView_`/`SysTreeView` 검색 결과 0건, 작성 시 직접 확인). 2패널 구조만 있음(research 자료 #36).

## 3. 요구사항

- FR-10-1 아카이브를 S1에서 열면(파일 연결, S7-05 "미리보기로 열기", 끌어 놓기) 풀지 않고 S1-14에 최상위 항목을 보여 준다.
- FR-10-2 S1-13 폴더 트리는 아카이브 내부 폴더 구조를 보여 주고, 트리에서 폴더를 고르면 S1-14가 그 폴더 내용으로 바뀐다.
- FR-10-3 S1-14 열은 이름, 크기, 압축 크기, 수정한 날짜, 형식. 열 머리 클릭 = 정렬. 암호화된 항목은 암호 아이콘을 표시한다.
- FR-10-4 S1-14에서 폴더 더블클릭 = 들어가기, `Backspace` = 상위 폴더, `Alt+←` = 뒤로(S1-10).
- FR-10-5 S1-11 브레드크럼은 "아카이브 이름 › 폴더 › 폴더"로 표시하고, 단계를 클릭하면 그 폴더로 이동한다.
- FR-10-6 S1-14에서 항목을 고르면 S1-17에 크기(압축 크기), 수정 시각, CRC32를 보여 준다. 아카이브가 해당 속성을 제공하지 않으면 그 줄을 숨긴다.
- FR-10-7 S1-21에 파일·폴더 개수, 원본→압축 크기(비율), 형식·방식, 암호화 여부, 선택 항목 크기를 표시한다.
- FR-10-8 목록 보기는 아카이브 파일을 바꾸지 않는다(읽기만).

## 5. 동작 규칙과 예외

- 파일 목록이 암호화된 7z(헤더 암호화)는 열 때 S6를 띄우고, 취소하면 S1에 아무것도 열지 않는다.
- 아주 큰 아카이브(항목 10만 개 이상)는 목록을 읽는 동안 S1-14에 진행 표시를 하고 UI가 멈추지 않아야 한다.
- 아카이브에 폴더 항목이 따로 없고 경로로만 폴더가 있는 경우에도 트리에 폴더가 보인다(7-Zip Agent의 가상 폴더 구성을 따름).
- 손상된 아카이브는 열 수 있는 만큼 보여 주고 S1-21에 경고를 표시한다. 세부는 #20(F20), #24(F24).
- 분할 아카이브 조각 상태는 #33(F33)에서 S1-21에 추가한다.
