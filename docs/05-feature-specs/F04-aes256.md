## 1. 목적

압축 파일에 암호를 걸 때 사용자가 암호화 방식을 몰라도 안전한 방식(AES-256)이 적용되게 한다. 7-Zip은 ZIP에서 오래된 ZipCrypto가 기본값이라 사용자가 고르지 않으면 약한 암호화가 된다. j-zip은 AES-256을 기본으로 하고, 호환성이 필요한 경우만 바꾸게 한다.

## 2. 현재 7-Zip 동작

- 암호 구현: `CPP/7zip/Crypto/7zAes.cpp`(7z), `WzAes.cpp`(ZIP AES), `ZipCrypto.cpp`.
- 압축 대화상자: 암호 `IDE_COMPRESS_PASSWORD1`(120), 확인 입력 `IDE_COMPRESS_PASSWORD2`(121), 방식 콤보 `IDC_COMPRESS_ENCRYPTION_METHOD`(122), 보기 체크 `IDX_PASSWORD_SHOW` (`CPP/7zip/UI/GUI/CompressDialogRes.h:27-29`, `:42`).
- `CCompressDialog::SetEncryptionMethod()` (`CompressDialog.cpp:1721`): 7z면 "AES-256"만. ZIP이면 "ZipCrypto", "AES-256" 순으로 넣고, 레지스트리 값이 `aes`로 시작할 때만 AES-256을 선택함. 즉 **ZIP 기본값은 ZipCrypto** (`:1742-1748`).
- 파일 이름 암호화: `kFF_EncryptFileNames`는 7z에만 있음 (`CompressDialog.cpp:286-287`), 컨트롤 `IDX_COMPRESS_ENCRYPT_FILE_NAMES`.
- 확인 단계 `OnOK` (`CompressDialog.cpp:1066-1095`): ZIP이면 암호가 ASCII가 아니면 `IDS_PASSWORD_USE_ASCII` 오류, ZIP AES면 99자 초과 시 `IDS_PASSWORD_TOO_LONG`, 보기를 끈 상태에서 두 입력이 다르면 `IDS_PASSWORD_NOT_MATCH`.
- 해제 시 암호 입력: `CPP/7zip/UI/FileManager/PasswordDialog.cpp`, 해제 대화상자 `IDE_EXTRACT_PASSWORD 120` (research 자료 #23).

## 3. 요구사항

- FR-04-1 S3-08에 암호를 넣으면 7Z·ZIP·EXE 모두 AES-256으로 암호화한다. ZIP의 기본값도 AES-256이다.
- FR-04-2 ZIP에서 ZipCrypto는 고급 패널에서만 고를 수 있고, 고르면 "오래된 방식이라 보안이 약함 · 다른 프로그램 호환용" 안내를 함께 보여 준다(S3-16).
- FR-04-3 S3-08은 C12 규칙대로 보기 토글을 가진다. 보기가 꺼져 있으면 확인 입력을 한 번 더 받고, 두 값이 다르면 S3-12를 비활성화하고 입력 아래에 "두 암호가 다름"을 표시한다.
- FR-04-4 ZIP에서 ASCII가 아닌 문자(예: 한글)가 들어간 암호는 입력 즉시 오류("ZIP 암호는 영문·숫자·기호만 가능 · 한글 암호는 7Z 형식 사용")를 표시하고 S3-12를 비활성화한다. ZIP AES에서 100자 이상도 같은 방식으로 막는다.
- FR-04-5 S3-09 "파일 이름도 숨기기"는 7Z·EXE에서만 활성. ZIP·TAR.GZ에서는 비활성 + 이유 툴팁("ZIP은 파일 이름을 숨길 수 없음").
- FR-04-6 TAR.GZ처럼 암호화를 지원하지 않는 형식(`kFF_Encrypt` 없음)을 고르면 S3-08 전체를 비활성화하고 이유 툴팁을 보여 준다. 이미 입력된 암호가 있으면 형식 변경 시 "이 형식은 암호를 지원하지 않음" 안내를 표시한다.
- FR-04-7 암호가 걸린 아카이브를 열거나 풀 때 암호가 필요하면 S6 암호 입력 창을 띄운다. S6-01에 파일 이름, 아카이브 이름, 암호 방식(예: "AES-256")을 표시한다.
- FR-04-8 S6-06 "건너뛰기"는 해당 파일만 제외하고 계속한다. S6-05 "나머지 파일에도 사용"을 켜면 같은 아카이브 안 다른 파일에 같은 암호를 다시 묻지 않는다.

## 5. 동작 규칙과 예외

- 암호를 틀리면 S6를 다시 띄우고 "암호가 맞지 않음"을 표시한다. 해제 중 CRC 오류로만 틀린 암호가 드러나는 형식(ZipCrypto 등)은 S9-02 "암호 틀림"으로 분류한다.
- 7Z에서 S3-09를 켜지 않으면 파일 목록은 암호 없이 보인다. 이것을 S3-09 툴팁에 적는다.
- 분할(#1)과 함께 쓸 수 있다.
- 저장된 암호 자동 시도(S6-02, S6-09)는 #23(F23)에서 다룬다.
