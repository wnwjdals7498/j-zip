## 1. 목적

사진이 많은 아카이브에서 원하는 파일을 찾으려면 지금은 하나씩 열어 봐야 한다. 목록에서 이미지를 고르면 오른쪽 미리보기 창에 썸네일과 해상도를 바로 보여 줘서, 풀기 전에 내용을 확인하고 필요한 것만 고를 수 있게 한다.

## 2. 현재 7-Zip 동작

- FileManager에서 "thumbnail", "preview", `IThumbnailProvider`, GDI+ 검색 결과 0건. `MyWindowsNew.h:111`의 `SetThumbnailTooltip`은 작업 표시줄 API이며 이 기능과 무관하다 (research #26).
- 사용자가 이미지를 보려면 더블클릭이나 `F3`으로 임시 폴더에 풀어 외부 프로그램으로 연다. 이 경로는 `PanelItemOpen.cpp`의 임시 추출(`kTempDirPrefix "7zO"`, `:48`)을 쓴다 (research #15).
- 7zFM 창은 패널(1개 또는 2개)만 있고 별도 미리보기 영역이 없다.

## 3. 요구사항

- FR-26-1 S1에 미리보기 창(S1-16, S1-17)을 두고, S1-07 "보기 ▾" 메뉴에서 켜고 끌 수 있다. 상태는 다음 실행 때도 유지한다.
- FR-26-2 S1-14에서 이미지 파일 1개를 선택하면 S1-16에 비율을 유지한 썸네일을 표시한다. 지원 형식: JPEG, PNG, GIF(첫 프레임), BMP. 그 밖의 형식은 형식 아이콘을 표시한다.
- FR-26-3 S1-17에 크기(압축 크기), 수정 날짜, CRC32를 표시하고, 이미지면 해상도(가로 × 세로)도 표시한다.
- FR-26-4 썸네일 생성은 UI 스레드를 막지 않는다. 생성 중에는 S1-16에 진행 표시를 두고, 다른 항목을 선택하면 이전 생성 작업을 취소한다.
- FR-26-5 크기 제한을 넘는 항목(기본 50 MB)은 자동으로 썸네일을 만들지 않고 "미리보기를 만들려면 클릭" 상태로 둔다.
- FR-26-6 암호가 걸린 항목은 자동으로 풀지 않는다. 암호를 아직 입력하지 않았다면 잠금 아이콘과 "암호가 필요함"을 표시한다.
- FR-26-7 썸네일용으로 푼 임시 데이터는 미리보기를 닫거나 아카이브를 닫을 때 지운다.
- FR-26-8 여러 항목을 선택하면 썸네일 대신 "N개 선택 · 합계 크기"를 표시한다.

## 5. 동작 규칙과 예외

- 디코딩 실패(손상 이미지, 지원 안 되는 하위 형식): 형식 아이콘으로 대체하고 오류 대화상자는 띄우지 않는다.
- 솔리드 7z에서는 뒤쪽 항목 하나를 보려 해도 앞부분을 풀어야 해서 느리다. 이 경우에도 FR-26-4의 취소 규칙으로 UI가 멈추지 않아야 한다.
- 이미지 디코더는 신뢰할 수 없는 입력을 다루므로, 디코딩 오류가 `JZip.exe` 프로세스를 종료시키면 안 된다.
- #16 주석(S1-18)과 같은 미리보기 창 안에 있다. 주석이 없으면 S1-18만 숨긴다.

## 7. 구현 지점

- `JZip.exe`(WinUI 3) S1 화면: 미리보기 창(S1-16~S1-18)과 창 분할(C19)을 새로 만든다. 7zFM의 `CPP/7zip/UI/FileManager/Panel.cpp`/`Panel.h`, `App.cpp`는 수정하지 않는다(현재 레이아웃 근거, research #26).
- `JZip.exe` 이미지 디코딩: **WIC**(Windows Imaging Component)로 메모리 스트림을 디코딩하고 축소한 비트맵을 S1-16에 표시한다([07. 기술 스택](../07-tech-stack.md) 7절). 디코딩은 백그라운드 스레드에서 하고 취소 토큰으로 이전 작업을 멈춘다(FR-26-4).
- `jzip-core` 데이터 추출: 기존 파일 `CPP/7zip/UI/FileManager/PanelItemOpen.cpp`의 임시 추출 방식(research #26, #15)을 참고해 항목 하나를 메모리 또는 임시 폴더로 푸는 함수를 둔다.

- [ ] 암호가 걸린 ZIP 안 JPEG를 선택하면 S6이 뜨지 않고 "암호가 필요함"이 표시된다.

## 9. 범위 밖·미결 사항

- 범위 밖: 동영상 프레임 썸네일, PDF·문서 미리보기, 목록의 "큰 아이콘" 보기에서 항목마다 썸네일 표시(S1-07의 "목록/큰 아이콘"은 보기 방식 전환만 다룬다).
- 해결: 이미지 디코딩은 WIC로 한다(07 문서 7절).
- 미결: HEIC·WebP 지원 범위(WIC 코덱이 설치된 PC에서만 디코딩되는 형식을 FR-26-2에 넣을지).
- 미결: 디코딩을 별도 프로세스로 격리할지 여부.
- 미결: 7zFM의 2패널 구조(`IDM_VIEW_TWO_PANELS`)를 `JZip.exe`에 둘지(#36 9절과 같은 결정). 디자인은 1패널 + 오른쪽 미리보기만 보여 주며, 2패널을 두지 않으면 미리보기 창은 창 오른쪽에 하나만 둔다.
