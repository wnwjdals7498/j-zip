# 04. GUI 레퍼런스

반디집의 화면 구성 **패턴**을 참고해 새로 설계한 j-zip GUI 명세. 반디집의 화면·아이콘·브랜딩은 복제하지 않는다.

- 디자인 캔버스(비공개): https://claude.ai/artifact/YXWMXQRdYEgcDggGNiRicM
- 아트보드 원본: [`gui-mockups/`](gui-mockups/) — 캔버스 런타임용 `.dc.html` 파일이라 브라우저에서 단독으로 열면 그대로 렌더링되지 않는다
- 각 화면의 `#번호`는 [03. 기능 벤치마크](03-feature-benchmark.md)의 기능 번호

## 설계 원칙

1. **자주 쓰는 동작은 클릭 한 번**: 우클릭 메뉴 최상단에 스마트 풀기, "이름.zip으로 압축"
2. **간단 기본, 고급은 숨김**: 압축 대화상자는 간단/고급 전환. 현재 7-Zip은 모든 옵션을 한 화면에 나열
3. **결과를 미리 보여줌**: 해제 후 폴더 구조, 예상 압축 크기·시간, 인코딩 적용 결과
4. **끝난 뒤 할 일을 이어줌**: 폴더 열기, 원본 휴지통, 완료 알림
5. **접근성**: 터치 대상 ≥ 32px(데스크톱), 텍스트 대비 4.5:1 이상, 아이콘 전용 버튼에 이름 제공

## 화면 명세

| 경로 줄 | 뒤로·상위, 브레드크럼, **파일명 인코딩 칩**(자동 감지 결과, 클릭 시 S5) | #17 |

### S2 · 압축 풀기 (640×580)

- 풀 위치 입력 + 찾아보기, 빠른 선택 칩: 원본과 같은 위치 / 바탕 화면 / 최근 경로
- 폴더 만들기 (#13)
  - **스마트(권장)**: 최상위 항목이 하나면 그대로, 여러 개면 아카이브 이름 폴더 생성
  - 항상 아카이브 이름으로 폴더 만들기
  - 폴더 없이 그대로
- 결과 미리보기 한 줄 (실제 생성될 경로)
- 옵션: 끝나면 폴더 열기(#30), 끝나면 원본 휴지통(#31), tar.gz 한 번에 풀기(#12), 같은 파일 처리(묻기/덮어쓰기/건너뛰기/이름 바꾸기), 파일명 인코딩(#17)
- 하단: "다음부터 묻지 않고 이대로 풀기", 취소, **풀기**

### S3 · 새로 압축 (720×760, 인터랙티브)

- 헤더 우측 **간단 / 고급** 전환
- 저장할 파일 경로
- 형식 카드: ZIP(어디서나 열림) / 7Z(가장 작게) / EXE(프로그램 없이 풀림) / TAR.GZ(리눅스·서버용) (#5 #6)
- 압축 수준: 저장만 / 빠름 / 보통 / 최고 + 예상 크기·시간
- 나눠서 압축 프리셋: 나누지 않음 / 메일 첨부(25MB) / USB FAT32(4GB) / 직접 입력 (#1)
- 암호 + "저장된 암호 ▾", 파일 이름 숨기기(7Z만) (#4 #23)
- 고급(펼침): 압축 방식, 사전 크기, CPU 스레드(#3), 솔리드, 압축 후 원본 삭제, 파일명 UTF-8 저장
- 하단: "이 설정을 기본값으로", 취소, **압축**

### S4 · 진행 / 완료 알림 (560×480)

- 진행창: 진행 막대, 처리량·속도·남은 시간·파일 수, 현재 파일, 끝나면 폴더 열기 / 창 닫기(#32), 대기열 표시, 백그라운드로·일시정지·취소
- 창을 닫으면 완료 시 Windows 토스트 알림: 결과 요약, "폴더 열기", "압축 파일 휴지통으로" (#30 #32)

### S5 · 파일명 인코딩 (640×500)

- 안내: "이 ZIP에는 파일명 인코딩 정보가 없음. 한국어(CP949)로 읽으면 가장 자연스러움"
- 왼쪽: 인코딩 후보와 감지 점수 (CP949 / UTF-8 / Shift-JIS / GBK / CP437)
- 오른쪽: 선택한 인코딩 적용 결과와 기존 7-Zip 표시(깨진 글자)를 나란히 비교
- "인코딩 정보 없는 ZIP은 항상 자동 감지" (#17)

### S6 · 암호 입력 / 암호 관리자 (880×500)

- 암호 입력: 대상 파일·아카이브·암호 방식, "저장된 암호 N개를 먼저 시도했지만 맞지 않음" 안내, 보기 토글, 관리자에 저장, 나머지 파일에도 사용
- 암호 관리자(#23): 이름·마스킹된 암호·마지막 사용·편집, 자동 시도 켜기, Windows Hello 확인 옵션
- 저장 방식: Windows 계정 기반 암호화(DPAPI), 다른 PC로 복사해도 열리지 않음

### S7 · 탐색기 우클릭 메뉴 (760×540)

- Win11 새 메뉴 최상단(#19): **여기에 풀기(스마트)**, **"이름\"에 풀기**, 7-Zip ▸
- 하위 메뉴: 다른 위치에 풀기…, 미리보기로 열기, 테스트, "이름.7z"로 다시 압축, 압축 옵션 지정…, 메뉴 항목 편집…
- 여러 개 선택 시 최상단: "각각 폴더로 풀기 (N개)", "하나로 압축" (#35)
- 일반 파일·폴더: "자료.zip으로 압축", "자료.7z로 압축" (#13)

### S8 · 설정 (920×620)

- 왼쪽 분류: 일반 / 압축 풀기(#30 #31) / 압축 / 탐색기 메뉴 / 연결 프로그램 / 보안(#21) / 화면·언어(#28 #22)
- 탐색기 메뉴 탭(#34 #19): 메뉴 방식(Win11 새 메뉴 + 추가 옵션 / 예전 메뉴만), 항목별 "맨 위에 / 7-Zip 안에 / 숨김", 아이콘 표시, Shift 누를 때만 표시
- 하단: 기본값으로 되돌리기, 취소, **저장**

### S9 · 테스트 결과 / 분할 파일 (760×480)

- 테스트 결과(#20 #24): 손상 개수 요약, 손상 파일과 오류 종류(CRC 오류, 데이터 끝남), Defender 검사 결과(#21), "정상 파일만 풀기", "복구 시도…", "결과 복사"
- 분할 파일(#33): 중간 조각을 열어도 첫 조각부터 자동으로 이어서 열기, 조각별 찾음/없음 표시, "빠진 조각 찾기…", "있는 만큼 풀기"

## UI 기술 선택지

현재 7-Zip GUI는 Win32 `.rc` 대화상자 기반이다.

| 선택지 | 장점 | 단점 |
|---|---|---|
| Win32 유지 + 커스텀 드로잉 | 기존 코드에서 점진적 변경 | 다크모드·고DPI 처리가 번거로움 |
| WinUI 3 / XAML Islands | 모던 UI 구현 용이, NanaZip과 같은 방향 | 대화상자 재작성 범위가 큼 |

권장: S2·S4·S5 같은 단순 대화상자부터 새 기술로 옮기고, S1(7zFM)은 마지막에 전환.
