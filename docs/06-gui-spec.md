# 06. GUI 명세서

j-zip GUI의 공통 규칙, 컴포넌트, 화면별 요소 목록을 정의한다.

- 화면 디자인 원본: [`../design/project/`](../design/project/) (형식은 [`design/README.md`](../design/README.md))
- 화면 개요와 디자인 토큰: [04. GUI 레퍼런스](04-gui-reference.md)
- 기능별 세부 명세: [05. 기능 세부 명세](05-feature-specs/README.md)
- **요소 ID**(예: `S2-07`)는 이 문서에서 정의하고, 기능 세부 명세가 이 ID로 화면 요소를 가리킨다.

> 디자인 파일의 분홍 배지(`.tag`, `#번호`)는 기능 추적용 표시일 뿐이며 **실제 앱에는 나타나지 않는다**.

## 2. 레이아웃

- 기준 단위 4px. 대화상자 안쪽 여백 좌우 20px, 상하 18px. 그룹 간격 16px, 그룹 안 간격 8px
- 대화상자 구조: **제목 줄(40px) → 본문 → 하단 버튼 줄(58px)**
- 하단 버튼 줄: 왼쪽에 "기억하기" 계열 체크박스, 오른쪽 끝에 `[취소] [기본 버튼]` (기본 버튼이 가장 오른쪽)
- 라벨은 입력 위에 둔다(왼쪽 라벨 금지). 예외: 한 줄짜리 드롭다운 옵션(`같은 파일: [▾]`)
- 텍스트 길이는 영어 기준 +30% 여유를 둔다(다국어)

## 3. 디자인 토큰

[04. GUI 레퍼런스 › 디자인 토큰](04-gui-reference.md#디자인-토큰-초안)을 따른다. 컴포넌트는 색을 직접 쓰지 않고 토큰 이름으로 참조한다.

| 토큰 | 용도 |
|---|---|
| `bg` | 창 배경 |
| `chrome` | 탭 줄, 상태 줄, 바깥 배경 |
| `surface` | 목록, 입력, 카드 |
| `border` | 구분선, 입력 테두리 |
| `text` / `muted` | 본문 / 보조 텍스트 |
| `accent` / `accentSoft` / `accentText` | 주요 동작, 선택 배경, 선택 글자 |
| `sel` | 선택 행 배경 |
| `success` / `warning` / `danger` | 상태 표시 (+ 각각의 연한 배경) |

## 4. 컴포넌트

공통 상태: 기본 / 마우스 올림 / 누름 / 키보드 포커스 / 비활성. 키보드 포커스는 2px `accent` 바깥 테두리를 항상 표시한다.

| ID | 컴포넌트 | 크기 | 규칙 |
|---|---|---|---|
| C01 | 기본 버튼 | 높이 34, 좌우 22 | `accent` 배경 + 흰 글자. 대화상자당 1개. `Enter`로 실행 |
| C02 | 보조 버튼 | 높이 34, 좌우 14–18 | `surface` 배경 + `border` 테두리 |
| C03 | 텍스트 버튼 | 높이 34 | 배경 없음, `accent` 글자. "기본값으로 되돌리기" 등 |
| C04 | 아이콘 버튼 | 30–40 정사각 | 툴팁과 접근성 이름 필수 |
| C05 | 툴바 버튼 | 높이 56, 최소 폭 64 | 아이콘 22px 위 + 라벨 12px 아래. 주요 동작 1개만 `accent` 배경. `▾`는 분할 버튼(본체 = 기본 동작, 화살표 = 메뉴) |
| C06 | 칩 | 높이 26, 둥근 13 | 빠른 선택. 선택됨 = `accentSoft` 배경 + `accent` 테두리 |
| C07 | 상태 칩 | 높이 30, 둥근 15 | 현재 상태 표시 + 클릭 시 변경(예: 인코딩 칩) |
| C08 | 세그먼트 | 높이 28–30 | 2–4개 중 하나. 선택 칸만 `surface` 배경 |
| C09 | 선택 카드 | 높이 ≈ 56 | 라디오와 같음. 제목 + 한 줄 설명. 선택 = 2px `accent` 테두리 + `accentSoft` |
| C10 | 라디오 / 체크박스 | 16px + 라벨 | 라벨 전체가 클릭 영역 |
| C11 | 드롭다운 | 높이 28–34 | 현재 값을 그대로 표시. 자동 값은 "자동 (감지 결과)" 형식 |

| C13 | 경로 입력 | C12 + C02 "찾아보기…" | 존재하지 않는 경로는 풀 때 생성. 잘못된 문자는 즉시 오류 표시 |
| C14 | 안내 배너 | 패딩 8–10, 둥근 6 | 정보(`accentSoft`), 경고(연한 `warning`), 오류(연한 `danger`). 아이콘 + 한두 줄 |

| C16 | 목록 | 행 높이 30–32 | 열 머리 클릭 = 정렬. 선택 행 = `sel` 배경 + 왼쪽 3px `accent` 선 |
| C17 | 트리 | 행 높이 30 | 단계마다 들여쓰기 14px |

## 5. 상호작용 공통 규칙

### 키보드

| 키 | 동작 | 범위 |
|---|---|---|
| `Enter` | 기본 버튼 실행 / 목록에서 열기 | 전체 |
| `Esc` | 취소·닫기 | 대화상자 |
| `Ctrl+E` | 압축 풀기(S2) | S1 |
| `Ctrl+N` | 새로 압축(S3) | S1 |
| `Ctrl+T` / `Ctrl+W` | 새 탭 / 탭 닫기 | S1 |
| `Ctrl+Tab` | 다음 탭 | S1 |
| `Ctrl+F` | 검색 칸 포커스 | S1 |
| `F3` / `F4` | 보기 / 편집(기본 앱으로 열기) | S1 (7-Zip 기존 키 유지) |
| `Del` | 삭제(확인 후) | S1 |
| `Alt+←` / `Backspace` | 뒤로 / 상위 폴더 | S1 |
| `Ctrl+,` | 설정(S8) | S1 |

### 설정 기억

- 대화상자의 "기억하기" 체크박스가 켜졌을 때만 다음 기본값으로 저장한다
- 마지막 풀 위치, 최근 경로(최대 5개), 창 크기·위치, 열 폭, 정렬은 항상 기억한다

### 문구 원칙

- 버튼은 동사로 끝낸다: "풀기", "압축", "적용", "폴더 열기"
- 안내문은 한두 문장, 결과와 다음 행동을 같이 쓴다: "파일 2개가 손상됨 · 정상 파일만 풀 수 있음"
- 오류에는 원인과 해결 방법을 같이 쓴다. 내부 코드(HRESULT 등)는 "자세히" 안에만 둔다

### 접근성

- 모든 컨트롤에 접근성 이름. 아이콘만 있는 버튼은 툴팁 = 접근성 이름
- 텍스트 대비 4.5:1 이상, 색만으로 상태를 구분하지 않는다(글자·아이콘 병기)
- 탭 순서는 화면 읽기 순서(위→아래, 왼쪽→오른쪽)

### 테마·DPI

- 라이트 / 다크 / 시스템 설정 따르기 (S8 화면·언어)
- 100–300% 배율에서 아이콘·여백이 선명해야 한다. 아이콘은 벡터 또는 배율별 비트맵
