# 06. GUI 명세서

j-zip GUI의 공통 규칙, 컴포넌트, 화면별 요소 목록을 정의한다.

- 화면 디자인 원본: [`../design/project/`](../design/project/) (형식은 [`design/README.md`](../design/README.md))
- 화면 개요와 디자인 토큰: [04. GUI 레퍼런스](04-gui-reference.md)
- 기능별 세부 명세: [05. 기능 세부 명세](05-feature-specs/README.md)
- **요소 ID**(예: `S2-07`)는 이 문서에서 정의하고, 기능 세부 명세가 이 ID로 화면 요소를 가리킨다.

> 디자인 파일의 분홍 배지(`.tag`, `#번호`)는 기능 추적용 표시일 뿐이며 **실제 앱에는 나타나지 않는다**.

### 현재 7-Zip 대응

j-zip 화면은 모두 독립 WinUI 3 앱 `JZip.exe`에 새로 만든다(S7만 셸 확장 `jzip-shell.dll`). 아래 7-Zip 파일은 **현재 동작과 로직을 확인하는 근거**일 뿐이며 j-zip 화면을 그 파일 위에 고쳐 만들지 않는다. 화면이 쓰는 로직은 `jzip-core.lib`(7-Zip `UI/Common`, `UI/Agent` 기반)로 옮긴다. 구성은 [07. 기술 스택](07-tech-stack.md) 3절.

| j-zip 화면 | j-zip 구현 위치 | 현재 7-Zip 구현 위치 (7-Zip 26.04 소스, 동작 근거) |
|---|---|---|
| S1 메인 창 | `JZip.exe` 메인 창 | `CPP/7zip/UI/FileManager` (`App.cpp`, `Panel*.cpp`) |
| S2 압축 풀기 | `JZip.exe` 대화상자 | `CPP/7zip/UI/GUI/ExtractDialog.cpp`, `ExtractDialog.rc` |
| S3 새로 압축 | `JZip.exe` 대화상자 | `CPP/7zip/UI/GUI/CompressDialog.cpp`, `CompressDialog.rc` |

| S5 파일명 인코딩 | `JZip.exe` 대화상자 | 없음 (신규) |
| S6 암호 입력 | `JZip.exe` 대화상자 / 관리자 창 | `CPP/7zip/UI/FileManager/PasswordDialog.cpp` / 암호 관리자는 신규 |

## 2. 레이아웃

- 기준 단위 4px. 대화상자 안쪽 여백 좌우 20px, 상하 18px. 그룹 간격 16px, 그룹 안 간격 8px
- 대화상자 구조: **제목 줄(40px) → 본문 → 하단 버튼 줄(58px)**
- 하단 버튼 줄: 왼쪽에 "기억하기" 계열 체크박스, 오른쪽 끝에 `[취소] [기본 버튼]` (기본 버튼이 가장 오른쪽)
- 라벨은 입력 위에 둔다(왼쪽 라벨 금지). 예외: 한 줄짜리 드롭다운 옵션(`같은 파일: [▾]`)
- 텍스트 길이는 영어 기준 +30% 여유를 둔다(다국어)

## 3. 디자인 토큰

| 토큰 | 용도 |

| `success` / `warning` / `danger` | 상태 표시 (+ 각각의 연한 배경) |

## 5. 상호작용 공통 규칙

### 키보드

| 키 | 동작 | 범위 |
|---|---|---|
| `Enter` | 기본 버튼 실행 / 목록에서 열기 | 전체 |
| `Esc` | 취소·닫기 | 대화상자 |
| `Ctrl+E` | 압축 풀기(S2) | S1 |
| `Ctrl+Shift+N` | 새로 압축(S3) — `Ctrl+N`은 7zFM의 "파일 만들기"라 쓰지 않음 | S1 |
| `Ctrl+T` / `Ctrl+W` | 새 탭 / 탭 닫기 (마지막 탭이면 창 닫기 — 7zFM의 기존 `Ctrl+W` 동작과 호환) | S1 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 다음 탭 / 이전 탭 | S1 |
| `Ctrl+F` | 검색 칸 포커스 | S1 |
| `F3` / `F4` | 보기 / 편집(기본 앱으로 열기) | S1 (7-Zip 기존 키 유지) |
| `Del` | 삭제(확인 후) | S1 |
| `Alt+←` / `Backspace` | 뒤로 / 상위 폴더 | S1 |
| `Ctrl+,` | 설정(S8) | S1 |

7zFM 기존 단축키는 그대로 유지한다 (`CPP/7zip/UI/FileManager/PanelKey.cpp`, `resource.rc`): `F2` 이름 바꾸기, `F5` 복사, `F6` 이동, `F7` 폴더 만들기, `F9` 두 패널 전환, `Ctrl+N` 파일 만들기, `Ctrl+R` 새로고침, `Ctrl+Z` 주석 변경, `Ctrl+1`–`Ctrl+4` 보기 방식, `Ctrl+F3`–`Ctrl+F12` 정렬, `Ctrl+PgDn` 안으로 열기, `Shift+Enter` 밖에서 열기, `Alt+Enter` 속성, `Alt+F12` 폴더 기록, `Tab` 패널 전환. 새 단축키는 이 목록과 겹치지 않게 정한다.

### 설정 기억

- 대화상자의 "기억하기" 체크박스가 켜졌을 때만 다음 기본값으로 저장한다
- 마지막 풀 위치, 최근 경로(최대 5개), 창 크기·위치, 열 폭, 정렬은 항상 기억한다

### 문구 원칙

- 버튼은 동사로 끝낸다: "풀기", "압축", "적용", "폴더 열기"
- 안내문은 한두 문장, 결과와 다음 행동을 같이 쓴다: "파일 2개가 손상됨 · 정상 파일만 풀 수 있음"
- 오류에는 원인과 해결 방법을 같이 쓴다. 내부 코드(HRESULT 등)는 "자세히" 안에만 둔다

### 접근성

- 모든 컨트롤에 접근성 이름. 아이콘만 있는 버튼은 툴팁 = 접근성 이름
- 텍스트 대비 4.5:1 이상, 색만으로 상태를 구분하지 않는다(글자·아이콘 병기)
- 탭 순서는 화면 읽기 순서(위→아래, 왼쪽→오른쪽)

### 테마·DPI

- 라이트 / 다크 / 시스템 설정 따르기 (S8 화면·언어, S8-14)
- 모든 화면(S1–S9, D1–D3)은 다크 테마를 지원한다. 다크는 토큰 값만 바꿔서 만들며(3절, 04 토큰 표의 "다크" 열), 화면별 다크 전용 레이아웃·색 지정은 두지 않는다. 디자인 파일은 Main(`dark` 속성)만 다크 상태를 보여 주고, 나머지 화면은 이 규칙으로 다크를 만든다
- 100–300% 배율에서 아이콘·여백이 선명해야 한다. 아이콘은 벡터 또는 배율별 비트맵
- 구현: 테마는 WinUI 3 `RequestedTheme`(루트 요소)과 라이트/다크 테마 리소스(`ThemeDictionaries`)로 바꾸며, "시스템 설정 따르기"는 `ApplicationTheme`을 지정하지 않고 시스템 값을 따른다. 고대비는 WinUI 3 `HighContrast` 테마 리소스를 따른다. DPI는 WinUI 3의 모니터별 DPI(Per-Monitor V2) 기본 동작을 쓰고, 레이아웃 값(px)은 100% 기준 유효 픽셀(epx)로 적는다. 비공개 uxtheme API는 쓰지 않는다([07](07-tech-stack.md) 7절)
- S7은 탐색기가 그리므로 Windows 테마·탐색기 DPI를 따른다

```
탐색기 우클릭(S7)
 ├─ 여기에 풀기 / 이름 폴더에 풀기 ───────────────┐

                                                ▼
                     (암호 필요) → S6 ──→ S4 진행창
                                                │
                     (오류·경고) ← ─────────────┤
                         S9                     ▼
                                  끝나면 이 창 닫기 → S4 완료 알림
                                                      ├─ 폴더 열기
```
